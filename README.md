# Hi, I'm Adam 👋

I'm a senior full-stack developer based near Bristol, with 15+ years building web and mobile products. Most of my work is with TypeScript, React and Next.js, from frontend architecture and component libraries through to APIs, deployment and keeping things running in production.

I co-founded [Paper Trails](https://papertrails.io) with my brother. It's a web app that turns running, cycling and hiking data into personalised map prints. I built it and look after everything technical, including deployments, integrations, microservices, security and bug fixes. It originally had a React frontend and a PHP/Laravel backend in separate repos. I've recently overhauled it using Next.js, TypeScript and MongoDB. We've fulfilled thousands of personalised orders worldwide.

Recently, I've been learning Rust by contributing to [Strata](https://github.com/lgse/strata), a Linux file manager built with Rust and GTK4. My contributions include 3D model and ebook previews, keyboard tab controls, and fixes to how bookmarks behave across multiple windows.

I'm also building [Mapbox TUI](https://github.com/adamcbrewer/mapbox-tui), an open-source map explorer and journey planner for the terminal, written in Go. It's a bit like Google Maps in a terminal, powered by Mapbox, with an MCP server so AI agents can inspect activity files, compare routes and render text maps too.

I work agent-first, using coding agents and agentic harnesses every day. I've seen great results from combining them with clear specs, automated tests and my own review.

Away from code, I enjoy running, climbing, cycling and woodworking.

You can find more of my work at [brewerlogic.com](https://brewerlogic.com), or get in touch on [LinkedIn](https://www.linkedin.com/in/adamcbrewer).
